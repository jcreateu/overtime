# 초과근무 알림 Android 프로젝트 (초기 시제품)

## 포함 기능
- 시작 시각 저장 및 수정
- 50분 간격 알림 예약
- 다른 앱 위에 표시되는 이동식 타이머 창
- 오전 3시를 기준으로 근무일 키를 계산
- 앱 데이터는 앱 내부 SharedPreferences에 저장

## APK 빌드
1. PC에 Android Studio 최신 안정판을 설치합니다.
2. Android Studio에서 `OvertimeReminder` 폴더를 엽니다.
3. Android SDK Platform 35 설치를 허용하고 Gradle 동기화를 완료합니다.
4. `Build > Build Bundle(s) / APK(s) > Build APK(s)`를 선택합니다.
5. 빌드된 APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.
6. APK를 휴대폰으로 옮겨 설치합니다. 출처를 알 수 없는 앱 설치를 허용해야 할 수 있습니다.

## 최초 실행 시
- 알림 권한을 허용합니다.
- 타이머 창을 쓰려면 앱에서 `타이머 창 권한 설정`을 눌러 다른 앱 위에 표시 권한을 허용한 뒤 다시 돌아와 실행합니다.
- 정확한 50분 알림을 위해 Android 설정의 `알람 및 리마인더` 권한을 허용하는 것이 좋습니다.

## 중요: 시제품 한계
이 프로젝트는 설치·동작 검증을 거친 완성 APK가 아니라 빌드를 위한 초기 소스 프로젝트입니다. 이 실행 환경에는 Android SDK/Gradle 빌드 환경이 없어 APK를 여기서 컴파일하거나 실기기에서 시험하지 못했습니다. Android 제조사별 배터리 최적화, 재부팅 후 알림 재예약, 03:00 경계 시각 처리, 알림 시 오버레이 색상 점멸 등은 실제 설치 전 추가 구현·검증이 필요합니다. 특히 앱이 종료된 동안 03:00을 넘긴 경우 시작 시각 자동 재설정 로직은 시제품 수준이므로 업무용으로 쓰기 전 테스트해야 합니다.
